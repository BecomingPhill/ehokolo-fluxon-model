\section{Computational Methodology}
To validate the structural transitions over cosmic time, we analyzed 34 high-resolution checkpoints from the V12 structure formation simulation ($N=1024^3$ grid cells per rank). Each step records the numerical scalar amplitude field $\phi$.
According to the NLKG governing equations, the effective field density is calculated dynamically:
\begin{equation}
\rho(\mathbf{x}, t) = k_{\text{density}} \cdot \phi^2(\mathbf{x}, t)
\end{equation}
where $k_{\text{density}} = 0.01$ serves as the local coupling parameter. Matter structures (solitons) were defined statistically by isolating regions where $\rho(\mathbf{x}, t)$ exceeds the $99.99^{\text{th}}$ percentile of the universal simulation background.

For the most massive emergent network of connected voxels---termed the ``Alpha Core''---we compute the dimensionless Radius of Gyration ($R_g$) over the evolving simulation time steps $\tau$:
\begin{equation}
R_g(\tau) = \sqrt{ \frac{\sum_i m_i (\mathbf{r}_i - \mathbf{r}_{\text{cm}})^2}{ \sum_i m_i} }
\end{equation}
This metric quantifies the Lagrangian stability of the state-compression. A sudden collapse in $R_g$ represents a phase transition in the localized vacuum state, effectively a ``snap'' in the topological scaling factor.

\section{Python Implementation of 34-Checkpoint Time Series Scanner}

\begin{lstlisting}[language=Python, caption={Lagrangian Stability Scanner from Cosmic\_Chronology\_Validation.ipynb.}]
import os
import glob
import numpy as np
from scipy.ndimage import label

def scan_chronology_checkpoints(checkpoint_dir, k_density=0.01):
    """
    Scans a sequence of EFM simulation checkpoints and computes Alpha Core Rg time series.
    """
    chk_files = sorted(glob.glob(os.path.join(checkpoint_dir, "CHECKPOINT_step_*.npz")))
    timeline_rg = []
    
    for cfile in chk_files:
        data = np.load(cfile, allow_pickle=True)
        phi = data['phi_cpu'] if 'phi_cpu' in data else data['phi_final_cpu']
        step = int(data.get('t_step', 0))
        
        rho = k_density * (phi**2)
        thresh = np.percentile(rho, 99.99)
        labeled, num_features = label(rho > thresh)
        
        # Isolate dominant Alpha Core
        max_mass, alpha_rg = 0, 0
        for cid in range(1, num_features + 1):
            mask = (labeled == cid)
            mass = np.sum(rho[mask])
            if mass > max_mass:
                max_mass = mass
                voxels = np.argwhere(mask)
                cm = np.sum(voxels * rho[mask][:, None], axis=0) / mass
                disp_sq = np.sum((voxels - cm)**2, axis=1)
                alpha_rg = np.sqrt(np.sum(rho[mask] * disp_sq) / mass)
                
        timeline_rg.append((step, alpha_rg, max_mass))
        print(f"Step {step:06d} | Alpha Core Rg: {alpha_rg:.4f} | Mass: {max_mass:.6e}")
        
    return timeline_rg
\end{lstlisting}
